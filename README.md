# Dans Pisti

Bulutların üstünde dans eden sarı adam, CS 1.6 bıçağı ve arka planda *Music Sounds Better With You*.

- **Sol tık:** bıçak savurma, **sağ tık:** dürtme
- **Adama vurmak:** kill feed'e `lyrics.txt` dosyasındaki sıradaki satır yazılır
- **M** ya da sol üstteki nota düğmesi: müziği açar/kapatır

Saf HTML/CSS/JS, derleme adımı yok. GitHub Pages'te `main` dalının kökünden yayınlanır.

Yerelde çalıştırmak için:

```bash
python -m http.server 5173
```

İmleç: [Windows 7 Aero cursor set](http://www.rw-designer.com/cursor-set/windows-7-aero-1), RainyForrest (public domain).
